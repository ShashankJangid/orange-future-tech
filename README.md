## ✨ Features & Architecture

### 🎨 1. Apple Design System Web Platform
- **Modern Frosted Glass Cards**: Built using custom backdrop filters (`backdrop-blur-md`, HSL tailwind colors).
- **Interactive Bento Grid**: Dynamic service showcases (Custom AI Software, Embedded Hardware Systems, Enterprise Cloud APIs).
- **Password-Protected API Portal**: SHA-256 challenge authentication modal allowing instant client-side key sync with `.env` backends.

### 🤖 2. 24/7 Autonomous Agentic AI Engine
- **Lead Discovery & Web Auditing**: Automated health scanner auditing Core Web Vitals, page speed, SSL certificates, and mobile responsiveness.
- **Branded Report Compilation**: Generates 3-page executive technical diagnostic HTML & PDF audit reports.
- **Native Hostinger Agentic Mail Outreach**: Dispatches cold proposals natively from `teams@orangefuturetech.com` using Hostinger REST API.
- **Automated Social Media Publishing**: Generates and posts technical marketing content daily to **LinkedIn**, **Twitter/X**, and **Instagram**.
- **Real-Time Phone Telemetry**: Dispatches instant Telegram notifications on lead discoveries and proposal dispatches.

## 🚀 Quickstart & Setup

### 1. Install Frontend Dependencies & Start Dev Server
```bash
npm install
npm run dev
```

### 2. Launch Autonomous AI Engine
```bash
python3 ai-engine/agent_core.py
```

### 3. Launch Admin API Backend Server
```bash
python3 ai-engine/server.py
```
